# 競艇 単勝確率モデル（第1弾：尼崎）

実行: `python3 venues/amagasaki/run.py`（元データ `kdata/` は読むだけ。出力は `venues/amagasaki/results/`）
- `common/` 取込(data)・特徴量(features)・モデル(model)・判定と検証(evaluate)  ／ `venues/<場名>/` 設定と実行
- 他場: `venues/<場名>/` に config.py と run.py を足す（JCDを変える）。
- 未来情報の遮断: 選手/モーター履歴は「そのレースより前」の結果だけ。本番STはサンプリングで置換（学習のみ実測）。
  進入は枠なり固定。風・波は締切前の履歴がないため不使用。コース別の基準値は学習期間のみから算出。
- 公開リポジトリのため、このフォルダはコミットしない運用（予測・買い目が公開されるため）。
