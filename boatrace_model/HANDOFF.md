# 引継ぎ書：競艇 単勝確率モデル（尼崎）  作成 2026-11-27

PC側のClaude Codeで続きをやるための資料。まずこのファイルと `README.md` を読む。

## 1. 目的と現状
- 目的: 1マーク展開を確率で予測し、各艇の単勝（1着）確率を出す。尼崎で作り、全24場へ広げる。自動投票はしない。
- 現状: 尼崎は実装・検証済み。**確率の精度は合格、買いルールは不合格（不採用）**。

## 3. 使い方
```
# 検証（追記版kdataを指定。元のkdataは読むだけ）
KDATA=<kdata_追記版のパス> python3 boatrace_model/venues/amagasaki/run.py
# 指定日の予想（出走表CSVは docs/racers/racers_today.csv 形式）
KDATA=<kdata_追記版のパス> python3 boatrace_model/venues/amagasaki/predict_day.py docs/racers/racers_today.csv 20261127
```
- 必要: Python と numpy / pandas（scipy不要）。
- 構成: `common/`（data・features・model・evaluate）＋ `venues/amagasaki/`（config・run・predict_day）。他場は `venues/<場名>/` を足す（`config.py` の `JCD` を変える）。

## 4. モデル
- 材料: 枠、展示タイム、選手の過去成績、モーター、選手の過去ST（コース補正）。
- 予測: 選手の過去STから400回サンプリングして隊形（のぞき・凹み）を再現し、条件付きロジットの1着確率を平均。
- 未来情報の遮断: 履歴は「そのレースより前」の結果のみ。コース別基準値は学習期間のみから算出。進入は枠なり固定。風・波・潮は不使用（締切前の履歴がないため）。
- 出力: 6艇の単勝確率、本命、攻め艇、1号艇の危険度、判定、必要オッズ(1÷確率)、展開確率。

## 6. 既知の制約
1. 展示タイムは `boatrace.jp` の beforeinfo にある。**クラウドからは接続不可、PC側からは取れる**。展示なしだと「展示前予想」になる。
2. 回収率は確定単勝配当。直前オッズは無い。
3. 級別・当地勝率の履歴は無く、過去成績は自前集計で代用。
4. 学習データは約1年分（2025年9〜11月は欠け）。
5. 攻め艇・展開をもらう艇の定義は暫定で、本命のような検証はしていない。
6. kdataの単勝払戻に「特払い」等の非数値行がある（読込時に除外済み）。
7. 着コード7〜16の意味は不明（CLAUDE.md の未確認事項）。

## 7. 守るルール
- **元データ（`kdata/`、`predictions/`、`results/`）は書き換えない。**
- 未来の情報を混ぜない（そのレースの本番ST・結果は予測に使わない）。
- 当日予想は**レース前に**作る。結果が出てからの予想は「確認」であって予想ではない。
- **公開リポジトリ**。レースごとの確率・買い目（`predictions.csv`、`today_*.csv`）はコミットしない（`.gitignore` 済み）。CLAUDE.md の「買い目・確率は出さない」方針に合わせる。
- `regenPredictions.py` は使わない（CLAUDE.md (5)）。HARAN_TH など変更禁止の定数にも触れない。
