## 1. 目的と現状
- 目的: 1マーク展開を確率で予測し、各艇の単勝（1着）確率を出す。尼崎で作り、全24場へ広げる。自動投票はしない。
- 現状: 尼崎は実装・検証済み。**確率の精度は合格、買いルールは不合格（不採用）**。
- 2026-11-27 追加: 尼崎の**オリジナル展示（一周・まわり足）**を材料に追加できるようにした（`ORIGINAL=1`）。確率の精度は全期間で少し改善。買いルールは依然不合格。

## 3. 使い方（PowerShell）
```
$env:KDATA = "<リポジトリ>\kdata_追記版"
$env:ORIGINAL = "1"        # オリジナル展示入り。外すと従来モデル（結果は完全に同じ）
# オリジナル展示の取得（1日分 / 期間。期間指定は保存済みの日を飛ばす）
python boatrace_model/venues/amagasaki/fetch_original.py 20261128
python boatrace_model/venues/amagasaki/fetch_original.py 20261127 20261210
# 検証
python boatrace_model/venues/amagasaki/run.py
# 指定日の予想（展示・オリジナル展示はその場で尼崎サイトから取得する）
python boatrace_model/venues/amagasaki/predict_day.py docs/racers/racers_today.csv 20261128
```
- 必要: Python と numpy / pandas / requests / beautifulsoup4（scipy不要）。
- 構成: `common/`（data・features・model・evaluate・tenji）＋ `venues/amagasaki/`（config・run・predict_day・fetch_original）。他場は `venues/<場名>/` を足す（`config.py` の `JCD` を変える）。

## 4. モデル
- 材料: 枠、展示タイム、選手の過去成績、モーター、選手の過去ST（コース補正）。`ORIGINAL=1` で一周・まわり足（6艇平均との差）を追加。
- 予測: 選手の過去STから400回サンプリングして隊形（のぞき・凹み）を再現し、条件付きロジットの1着確率を平均。
- 未来情報の遮断: 履歴は「そのレースより前」の結果のみ。コース別基準値は学習期間のみから算出。進入は枠なり固定。風・波・潮は不使用。
- 出力: 6艇の単勝確率、本命、攻め艇、1号艇の危険度、判定、必要オッズ(1÷確率)、展開確率。

## 6. 既知の制約
1. **公式 `boatrace.jp` はこのPCから 403（Access Denied）**。突破はしない。展示は次の2つから取る:
   - 尼崎公式サイトのスマホ版「直前情報」（`fetch_original.py`。展示タイム・一周・まわり足・体重・チルト・風・波）。`X-Requested-With: XMLHttpRequest` が無いと空を返す。1リクエストごとに1.2秒待つ。
   - 予備: BoatraceOpenAPI previews ミラー（`common/tenji.py`）。**更新は1日2回程度（JST 11時台・深夜2時台）**で、締切前の当日予想には遅い。
2. 一周・まわり足は尼崎の独自計測。計測できないと「-」→ 空欄（6艇平均並み扱い）。直線タイムは尼崎には無い。
3. 回収率は確定単勝配当。直前オッズは無い。
4. 級別・当地勝率の履歴は無く、過去成績は自前集計で代用。
5. 学習データは約1年分（2025年9〜11月はkdataが欠け）。
6. 攻め艇・展開をもらう艇の定義は暫定で、本命のような検証はしていない。
7. kdataの単勝払戻に「特払い」等の非数値行がある（読込時に除外済み）。
8. 着コード7〜16の意味は不明（CLAUDE.md の未確認事項）。

## 7. 守るルール
- **元データ（`kdata/`、`predictions/`、`results/`）は書き換えない。**
- 未来の情報を混ぜない（そのレースの本番ST・結果は予測に使わない）。
- 当日予想は**レース前に**作る。結果が出てからの予想は「確認」であって予想ではない。
- **公開リポジトリ**。レースごとの確率・買い目（`predictions.csv`、`today_*.csv`）と、尼崎サイトから取ったオリジナル展示の生データ（`original/`）はコミットしない（`.gitignore` 済み）。
- `regenPredictions.py` は使わない（CLAUDE.md (5)）。HARAN_TH など変更禁止の定数にも触れない。
